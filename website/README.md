# Operator website

The screen the operator of عسّاس uses to set up and watch the drones.

- **Dashboard:** live map with the three drones, their paths, battery, flight time, speed and network delay, alarms and lost-link warnings
- **Storage:** alarm history, LiDAR data history and image data history
- **Setup:** choose the scan area within the drones' range; the paths are created automatically

The website currently runs on simulated data at 4× speed. To open it, download this folder and open `index.html` in a browser.
